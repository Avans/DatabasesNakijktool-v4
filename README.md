# DatabasesNakijktool v4

SQL-nakijktool voor Brightspace die volledig in de browser van de student draait.
De oefendatabases zijn SQLite (WebAssembly); er is geen server of database meer die uit kan vallen.

Gebruik op een Brightspace-pagina (zelfde tag als v2/v3):

```html
<wd-datab1 aid="21506"></wd-datab1>
<script src="https://<vercel-url>/datab1-component.js"></script>
```

Status: in opbouw.
